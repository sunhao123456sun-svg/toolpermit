# Support

- Use the [quickstart](docs/quickstart.md) and [troubleshooting guide](docs/troubleshooting.md) first.
- Open a GitHub bug report for reproducible defects. Include ToolPermit/Python/OS versions, mode,
  redacted configuration, expected behavior, actual behavior, and the smallest safe reproduction.
- Open a feature request for proposed scope changes.
- Use private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

ToolPermit is a volunteer open-source project. There is no guaranteed support response time. Never
post real credentials, unredacted audit databases, or sensitive MCP arguments in an issue.
