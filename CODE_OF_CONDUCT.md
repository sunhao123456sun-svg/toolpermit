# Community code of conduct

ToolPermit aims to be a safe, focused, and welcoming technical community.

## Expected behavior

- Be respectful, specific, and patient across differences in experience and background.
- Critique ideas and evidence, not people.
- Treat security reports, private data, and maintainer instructions responsibly.
- Accept correction, disclose conflicts of interest, and make room for other contributors.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, doxxing, deliberate disclosure
of private security reports, impersonation, spam, and sustained disruption are not accepted.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile contact channel.
Maintainers may edit or remove content, warn participants, temporarily restrict participation, or
permanently ban accounts based on severity and pattern. Reports will be handled as confidentially
as practical, but absolute confidentiality cannot be promised.

This policy applies in project repositories, discussions, issue trackers, review spaces, and events
where someone represents the project.
